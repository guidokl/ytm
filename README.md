# Voidceptions · Playlist Catalogue

A small overview of my YouTube Music playlists across genres, eras and the experimental edges, grouped by
genre family. Each title or cover opens the playlist in YouTube Music.

**Live:** https://ytm.neap.rip

A static page with small cover thumbnails: no tracking, no cookies, no backend. It can be installed as an app
(Chrome on Android: menu, then "Install app") and stays readable offline.

This repository keeps each published version of the page in `_page/`. The old address
https://guidokl.github.io/ytm/ forwards to ytm.neap.rip.
